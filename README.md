 # Superstore Sales Dashboard

## 📊 Project Overview
Sales data analysis for a retail superstore covering 2014–2017.

## 🔍 Key Insights
- Technology category leads with ₹22,97,201 total revenue
- West region is the top-performing region
- Q4 shows consistent seasonal demand spikes
- Canon imageCLASS 2200 is the #1 product by sales

## 🛠️ Tools Used
- Python (pandas, openpyxl)
- LibreOffice Calc / Microsoft Excel

## 📁 Files
- `Superstore_Dashboard_v4.xlsx` — Main dashboard with charts, KPIs, insights

## 📌 Dashboard Includes
- 5 KPI boxes (Sales, Profit, Orders, Best Category, Best Region)
- 6 Charts (Sales by Category, Region, Trend, Top 5 Products, Profit by Category/Region)
- Business Insights & Recommendations
